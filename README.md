✨ Features

📚 Chapter Tracker — Add chapters, select subjects, and mark chapters as completed.

✅ Task Manager — Create daily tasks and track completed assignments.

☕ Pomodoro Timer — Choose between 25-minute focus sessions, 5-minute short breaks, and 15-minute long breaks.

📊 Progress Tracker — View completed chapters, tasks, and overall chapter progress.

⏰ Live Clock — Display the current time and date.

💌 Motivational Quotes — Read inspiring reminders while studying.

🌱 Daily Intention Planner — Set and save your main study goal.

💾 Local Storage — Save chapters, tasks, and study progress in your browser.

📱 Responsive Design — Designed to work on desktop and mobile screens.
